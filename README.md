# LinguaHub

Đây là một hệ thống quản lý trung tâm ngoại ngữ mẫu được xây dựng bằng HTML, CSS và JavaScript thuần túy.

## Tính năng

- Tổng quan dashboard
- Quản lý học viên
- Quản lý giảng viên
- Quản lý lớp học
- Xem lịch học
- Ghi nhận thanh toán
- Dữ liệu được lưu trong trình duyệt bằng localStorage

## Cách chạy

1. Mở thư mục dự án trong VS Code.
2. Chạy file [index.html](index.html) trực tiếp hoặc mở bằng Live Server.
3. Nếu cần, có thể dùng một máy chủ tĩnh đơn giản:

```bash
python -m http.server 3000
```

Sau đó mở http://127.0.0.1:3000/.
